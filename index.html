Le mot de passe est haché (SHA-1) directement dans ton navigateur. Seuls les 5 premiers caractères du hash sont envoyés à l'API — jamais le mot de passe, ni le hash complet. C'est la méthode dite « k-anonymat » utilisée par Have I Been Pwned.

Base de données : Pwned Passwords (Have I Been Pwned), 600+ millions de mots de passe issus de fuites publiques.
Aucune donnée n'est stockée ni journalisée par cet outil.
